# 🔬 Research

## CHAIR — Persian Information Retrieval

My Master's research focused on improving information retrieval for **Persian question answering systems**.

I designed and implemented:

**CHAIR — Contextual Hybrid Artificial Intelligence Retrieval**

The framework combines lexical and semantic retrieval approaches.

### Main Components

* BM25
* ParsBERT
* Reciprocal Rank Fusion (RRF)
* Weighted Fusion
* Persian Text Preprocessing
* Vector Representations
* Result Reranking

The framework was evaluated using the **PQuAD dataset** with metrics including:

* Precision
* Recall
* MRR
* MAP
* NDCG
* F1

The research explored how combining lexical and semantic retrieval can improve the accuracy and stability of Persian information retrieval, particularly for short and ambiguous questions.
